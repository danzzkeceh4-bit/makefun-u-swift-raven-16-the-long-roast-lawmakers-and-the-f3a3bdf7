## The entry

One satirical sentence, 159 characters, roasting the lawmakers who vote to regulate artificial intelligence — then ask an intern why their Word document will not just become a PDF on its own.

> The committee that voted to regulate artificial intelligence spent this morning asking an intern why their Word document will not just become a PDF on its own.

## How it works

`main.ts` (Node 22, no dependencies, no network) writes exactly that one sentence to `/output/entry.txt` — no trailing newline. It validates the entry first (1–320 code points, exactly one sentence) and verifies the written file byte-for-byte with a read-back guard.

```bash
node main.ts
cat /output/entry.txt
```
